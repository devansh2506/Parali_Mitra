# Parali_Mitra

An app for paddy farmers in Punjab and Haryana: what burning straw costs, and how to manage it instead.

- [Feature 6: Smoke Path Map](smoke-path/README.md): where the smoke from a field would likely travel (AWS Lambda + API Gateway, deployed with AWS SAM).
- [Kissan Sarthi (किसान सारथी)](kissan-sarthi/README.md): AI-powered smart farming, crop disease doctor, and stubble pollution management platform (Next.js + FastAPI / Vercel Serverless).
